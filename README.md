# RepoMate-Lite

A RAG-based system that answers natural-language questions about a GitHub repository, using
hybrid search (vector + keyword) and syntax-aware chunking. See `CLAUDE.md` for the full
architecture, tech stack, and team conventions.

## Status

Initial module scaffold only — interfaces and folder structure are in place; implementation
has not started.

## Evaluation

No accuracy/latency/cost numbers are published yet. Per `CLAUDE.md`, any such number in this
README must come from an actual run of `eval/run_eval.py` — never an estimate.
